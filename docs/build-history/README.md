# AI build history

FINN was built with Claude Code (Claude Opus) over 11–15 Nov 2026. These are readable exports of the two sessions:

- **[build-session.md](build-session.md)**: the whole build, from reading the challenge brief and choosing the design, through data sources, push and pull features, Surya, deployment and polish. The context limit was reached twice; the summary points are marked in the log.
- **[logo-session.md](logo-session.md)**: the FINN logo design.

Each log shows the user's messages (with their answers to Claude's multiple-choice questions), Claude's replies, and a collapsed list of the actions behind each reply: files read and edited, commands run, browser checks.

Left out: Claude's internal reasoning, raw tool output and screenshots, which took the raw export to 53 MB. Local file paths are shortened to `~`, and a few personal email addresses used as examples are replaced with neutral stand-ins. The raw Claude Code exports (`.zip`) are available on request.
